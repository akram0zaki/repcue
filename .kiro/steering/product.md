# RepCue Product Overview

RepCue is a privacy-first fitness tracking Progressive Web App (PWA) designed for interval training and exercise logging. The app prioritizes user privacy by storing all data locally and offering optional cloud sync only with explicit user consent.

## Core Features

- **Interval Timer**: Configurable workout timers (15s, 30s, 60s) with pre-timer countdown
- **Exercise Library**: 20 core exercises across 5 categories (Core, Strength, Cardio, Flexibility, Balance)
- **Activity Logging**: Track workout sessions and progress
- **Mobile-First Design**: Optimized for phones and tablets with PWA capabilities
- **Privacy-First**: All data stored locally with optional cloud sync
- **Accessibility**: WCAG 2.1 compliant design
- **Internationalization**: Support for 6 languages with full RTL support for Arabic

## Key Principles

- **Privacy by Design**: No tracking, analytics, or external requests without consent
- **Offline-First**: Full functionality without internet connection
- **Self-Hostable**: Optimized for Raspberry Pi deployment
- **Accessibility**: Inclusive design for all users
- **Performance**: Fast loading and responsive interactions

## Target Users

- Privacy-conscious fitness enthusiasts
- Users wanting self-hosted fitness tracking
- Mobile-first workout tracking
- Interval training practitioners
