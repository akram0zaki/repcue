🔧 Clear Legal Acceptances - RepCue

⚠️ Development Tool
This page allows you to clear legal acceptances stored in localStorage for testing purposes.

Current Legal Acceptances

Actions

Manual Method (Browser Console)

You can also run these commands directly in your browser's developer console:

View Current Data:

const consent = JSON.parse(localStorage.getItem('repcue_consent'));
console.log('Legal Acceptances:', consent?.legalAcceptances);

Clear All Legal Acceptances:

const consent = JSON.parse(localStorage.getItem('repcue_consent'));
if (consent) {
    consent.legalAcceptances = [];
    localStorage.setItem('repcue_consent', JSON.stringify(consent));
    console.log('✅ Cleared all legal acceptances');
}

Clear Specific Document (e.g., terms_conditions):

const consent = JSON.parse(localStorage.getItem('repcue_consent'));
if (consent) {
    consent.legalAcceptances = consent.legalAcceptances.filter(a => a.docId !== 'terms_conditions');
    localStorage.setItem('repcue_consent', JSON.stringify(consent));
    console.log('✅ Cleared terms_conditions acceptance');
}

Clear All Consent Data:

localStorage.removeItem('repcue_consent');
console.log('✅ Cleared all consent data');
